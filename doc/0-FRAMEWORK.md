## 1. 一句话

《规矩古国》：一个方块风的 3D 小世界。小野是河谷古国的小匠师，村民带着实际麻烦来找他，
他用绳、桩、规、矩、竿、量器这些古人的工具动手解决。每解决一件事，河谷就长出一块新东西（田、城、塔、仓、渠）。

## 2. 核心循环（每一关都是这五步，1–3 分钟）

1. **麻烦来了**：村民一句话说事（配朗读），镜头给到现场。
2. **先猜**（有数量的关卡）：用步进器或点选，凭眼睛估一个数 / 选一个。不判对错，只记下来。
3. **动手**：拖、拉绳、切、拼、转、倒、搭。
4. **世界给后果**：做对了庄稼长出来、水流过去、塔立起来；没到位时世界给出看得见的差距（水流偏、塔歪），加一句「再调一调」。
5. **结算**：1–3 颗星 + 「眼力」（猜得多准）+ 可能解锁一张「古人智慧卡」。

## 4. 贯穿全局的设计

- **眼力值**：每次「先猜」的准确度都记下来，按类别（长度 / 面积 / 角度 / 高度 / 容积）显示最近几次的变化——
  对上他「比上次更准」的动机。只显示自己的进步，不排名。
- **古人智慧卡**：每章 2–3 张，一张图 + 两三句话（可朗读），讲真实历史里谁这么干过。收集册在地图上。
- **提示三档**：轻点一下「想一想」→ ① 一句方向提示 ② 幽灵虚影示范一步 ③ 自动演示这一步。用了提示不扣星，只是不加「独立完成」的小标记。
- **小老师关**：部分关卡是「学徒做歪了，请你指出来 / 改过来」，把他爱教人的劲用上。
- **不设**：倒计时、生命值、失败画面、排行榜、连续签到。

## 5. 技术方案

- **栈**：Vite + 原生 JavaScript（ES 模块 + JSDoc 注释）+ Three.js（3D）+ lucide（图标）+ vitest（测几何数学）。
  不用 React：界面只是盖在 3D 上的一层 DOM，用不着。
- **朗读**：先用浏览器自带的 `speechSynthesis`（零成本、不用服务器），可在设置里关。
  以后想换成更自然的声音，再接 `Product Library/tts/`。
- **音效**：WebAudio 现场合成（叮、咚、哗啦），不放音频文件。
- **存档**：`localStorage`，key 前缀 `geo_`，只存每关星数、眼力记录、已得卡片、设置。上限 20KB。
- **部署**：以后作为独立 Vercel 项目挂到 `kiwistudy.oldmao.com/geometry`（改 kiwistudy-hub 加一条转发）。
  **部署要用户点头才做。** vite 的 `base` 先做成可配置。

### 美术与手感

- **方块风小景**：低面数、平涂、暖色。像桌上的一盘微缩模型，不追求写实。
- **色板**：土 `#C9A66B`、田埂 `#8B6B43`、稻绿 `#7FB069`、深绿 `#4F7942`、河蓝 `#5BA4CF`、陶红 `#C8553D`、
  绳 `#E8D8B0`、木 `#A47148`、石 `#B8B2A7`、天空上 `#BFE3F5` 下 `#F6E9C9`、强调金 `#F2B134`。
- **单位**：1 个世界单位 ＝ 1 步。拖动默认吸附到半步或整步（关卡自己定）。
- **镜头**：默认斜 45° 俯看；右下角一个按钮切到正俯视（拖得准）；双指 / 右键转视角、捏合 / 滚轮缩放。
- **性能**：像素比上限 2，单场景三角面 < 5 万，阴影贴图 ≤ 1024，iPad 上稳 50 帧以上。
- **界面**：字大（正文 ≥ 18px）、按钮触控区 ≥ 48px、图标用 lucide 不用 emoji、可点的都有按下反馈。
  遵守 `MyLibrary/core/rules/design-global.md`。

## 6. 怎么验（每个阶段都一样）

1. `npm test` 绿（几何数学）。
2. `npm run build` 绿。
3. 浏览器里用 `?level=` 把本阶段每一关走一遍：能进、能玩到过关、控制台没有报错。
4. 截图看一眼：画面不难看、字看得清、按钮够大。
5. 手感（好不好玩、小野爱不爱玩）机器验不了，留给小野真机试。
